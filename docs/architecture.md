# Guinea Go Architecture

## Vision

Guinea Go est une plateforme numérique tout-en-un destinée au marché guinéen.

L'objectif est de proposer plusieurs services dans une seule plateforme.

## Modules

- Identity
- Shared
- Transport
- Hotels
- Events
- Education
- Commerce
- Payments
- Notifications
- Analytics
- Admin

## Architecture

Backend
